# 🚀 Space Shooter 3D

A fully playable 3D space shooter game built with Babylon.js. Destroy enemies, rack up your score, and survive as long as you can!

## ✨ Features

- **Full 3D Graphics** - Powered by Babylon.js rendering engine
- **Mobile & Desktop Support** - Touch controls for mobile, keyboard for desktop
- **Progressive Difficulty** - Enemy spawn rate increases over time
- **Particle Effects** - Explosive visuals when destroying enemies
- **3D Enemy Types** - Pyramids, cubes, and spheres with unique colors
- **Score & Lives System** - Track your progress and survivability

## 🎮 How to Play

### Desktop Controls
- **A/D or ← →** - Move left/right
- **W/S or ↑ ↓** - Move forward/backward
- **SPACE** - Shoot

### Mobile Controls
- **Virtual Joystick** (left side) - Move in any direction
- **Fire Button** (right side) - Tap or hold to shoot

## 🛠️ Technical Details

- **Engine**: Babylon.js
- **Graphics**: WebGL-based 3D rendering
- **Controls**: Keyboard + Touch input
- **Browser Support**: All modern browsers with WebGL support

## 🎯 Game Mechanics

- Destroy enemies to earn **100 points** each
- Start with **3 lives**
- Enemy difficulty increases as the game progresses
- Avoid collisions with enemy ships
- Enemies spawn faster over time
